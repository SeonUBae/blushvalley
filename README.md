## 구조

라이브러리 없이 HTML 파일 하나로 동작해요.

```
지도 → 캐릭터 → 신호 → 그리기
```

- **지도** 작업실을 2px 칸으로 나누고 가구 자리를 막아 둬요. 캐릭터는 8방향 탐색으로 길을 찾고, 직선으로 이어 걸어요.
- **캐릭터** 평소에는 각자 할 일을 골라서 해요. 신호가 들어오면 하던 일을 멈추고 반응해요.
- **신호** `누가`, `무슨 종류` 두 가지만 받아요. 작업 기록 파일 `events.json`이 있으면 그날의 기록을 신호로 바꿔 보여줘요.
- **그리기** 발 위치 기준으로 깊이를 정렬하고, 책상이나 소파 뒤에 있을 때는 가려서 그려요.

화면으로 가는 기록은 날짜, 누가, 무슨 종류 세 가지뿐이에요. 시각, 내용, 파일 이름은 이 저장소에 들어오지 않아요.

## 확인하기

- 주소 뒤에 `?debug`를 붙이면 막힌 칸과 캐릭터가 갈 길이 보여요.
- 오른쪽 아래 `log`를 누르면 작업 기록을 볼 수 있어요.
- `node tools/check-map.mjs`로 모든 장소에 걸어서 갈 수 있는지 검사해요. PR마다 Buzzi가 자동으로 실행해요.
